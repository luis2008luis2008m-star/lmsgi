Aprendiendo HTML

HTML significa HyperText Markup Language . Es el lenguaje utilizado para crear páginas web.

HTML: es un lenguaje de marcado que permite estructurar el contenido de una página web.

Como dijo Tim Berners-Lee: La web es más una creación social que técnica.

Ejemplo de texto preformateado:

            Mi primera página web
            Estoy aprendiendo HTML
            Este texto conserva los espacios
            y los saltos de línea.

HTML permite destacar y enfatizar determinadas palabras dentro de un texto.

Es muy importante utilizar correctamente las etiquetas HTML para crear páginas web accesibles.
